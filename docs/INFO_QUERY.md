# 资讯查询

工具箱新增“资讯查询”，第一个功能为“AI 模型能力与价格”。用户点击查询才访问
Artificial Analysis 的公开榜单，不需要 API 密钥，不发送记账、保险箱等本地数据。

数据源：<https://artificialanalysis.ai/leaderboards/models>。

默认图表与用户提供图片使用相同的指标：纵轴为 Artificial Analysis 智能指数，
横轴为 `intelligenceIndexCostPerTask`（美元 / 评测任务），使用对数轴。
模型厂商以颜色区分，点击圆点或列表显示详情，支持模型搜索、厂商筛选和放大缩放。
默认显示智能指数35分及以上的模型，从高到低排列；滑动条仅调整最低分数。
图表、图例、厂商菜单和模型明细均随下限联动，不限制厂商数量。厂商支持多选，
选中的厂商模型合并展示；清空选择恢复全部，取消弹窗不改变筛选。新下限不再
包含的厂商从选择中移除，其余选择保留；无剩余选择时恢复全部符合条件的厂商。
虚线表示帕累托优势前沿。绿色区域按当前入图模型的成本和能力中位数划分，含义为
相对低成本、高能力；其边界并非源站的固定阈值。图上的标签会避让重叠。

缺失任务成本不会从其他字段推算；免费模型和未公布成本的模型仍保留在列表中，
不能放入对数轴。可切换输入或输出 Token 单价，但界面明确标注口径不同。
不同时间的智能指数评测口径可能变更，不能仅凭分数直接比较历史能力进步。

仅使用公开 HTML 内嵌的 JSON 数据，不执行网页脚本，也不绕过认证或验证码。
网页结构变化、限流和网络失败时提供原因及原始榜单入口，不填充虚构数据。
每次查询显示获取时间，该时间不是官方数据更新时间；最新程度取决于源站更新。
结果以结构化 JSON 缓存在本地 SQLite 的 app_settings 中，失败时保留旧图并标记缓存。
模块注册和应用启动不会请求榜单。

验证：`flutter test test/modules/info_query`。测试包含源站已公开字段结构的解析、
任务成本与 Token 价格区分、跨数据分块、缓存、错误反馈、图表定位和模块注册。

已使用真实公开榜单验证查询和模型解析。源站当前的每任务成本为数字字段，
解析同时兼容旧缓存的嵌套结构。手机/Windows 查询使用设备自己的网络。

2026-10-29 的公开榜单将正式数据放在 `initialModels` 数组中，记录以 `slug`
标识，不再提供 `id`。解析器兼容新旧数组名，后备解析也可使用 `slug` 识别模型；
导航中的同名模型缺少智能指数，不作为榜单数据。已加入当前源站记录的回归样本，
缺少任务成本或 Token 单价时继续保持缺失。
