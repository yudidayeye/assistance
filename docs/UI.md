# 视觉设计

优化APP整体的UI展示，要求如下：

## 整体气质

这个页面的核心气质可以概括为：
“安静的科技感 + 温和的健康陪伴 + 轻商业化引导”

关键词：
Calm（平静）
Soft tech（柔和科技）
Restorative（恢复感）
Non-intrusive（不打扰）

## 色彩系统

1. 主色
   核心品牌色
   睡眠 / 恢复 / 夜间
   科技感但不冰冷
2. 辅助色
   淡蓝（数据辅助）
   薄荷绿（健康指标）
   柔粉（情绪/品牌氛围）
3. 背景系统
   大面积浅色或渐变背景
   夜间主题页使用“柔光渐变”
   几乎没有纯白硬背景
4. 色彩特点总结
   低对比
   高柔和度
   轻渐变过渡
   避免纯色冲击

## 布局结构（Layout Logic）

### 1. 单焦点中心结构

典型结构是：
一个核心指标 + 周边弱信息

特点：
主数据居中最大化
次级数据环绕/下移
信息密度低

### 2. 模块化卡片流

每个信息块是独立卡片
卡片之间留白明显
视觉“漂浮感”

### 3. 层级非常清晰

层级顺序：
核心状态
小型指标
功能入口
订阅推广

## 要避免的设计问题（非常重要）

1. 过度高对比
   避免：
   黑白强对比
   纯黑背景 + 亮色UI
   高饱和红/绿警示风
   会破坏“健康舒缓感”

2. 信息密度过高
   避免：
   一屏塞太多数据
   表格化健康信息
   KPI 堆叠
   会变成“医疗仪表盘”，失去陪伴感

3. UI 太硬（sharp UI）
   避免：
   小圆角（<8px）
   硬边框卡片
   强阴影分层
   会变得“企业后台风”

4. 情绪断裂（很关键）
   避免：
   数据页很科技冷
   订阅页突然变商业促销风
   应该统一“温和健康叙事”，不能割裂

5. 颜色过多
   避免：
   多主色系统（>3种主色）
   每个模块不同风格
   会破坏“品牌一致性”
