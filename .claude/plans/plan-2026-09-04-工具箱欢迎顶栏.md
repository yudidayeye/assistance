# 计划：工具箱顶栏改「欢迎区」

日期：2026-09-04（需求见 `requirement-2026-09-04-工具箱欢迎顶栏.md`）

## 数据源收口（关键）

`user_name`/`user_avatar` 原本仅 profile 页直连 DB、无通知源。方案：并入现有 `SettingsService`/`SettingsController`（已是 ChangeNotifier，MainShell 已监听），让工具箱顶栏与 profile 共用同一通知链；导入恢复的 `reload()` 已走 `loadSettings()`，零新增接线自动覆盖。

## 改动清单

1. `lib/core/settings/settings_service.dart`
   - `static const String defaultUserName = '用户';`
   - 缓存 `_userName` / `_avatarB64`（空串规整 null）+ getter `userName`/`avatarB64`
   - `loadSettings()` 内加 `_loadUserProfile()`（两条单键查询）
   - `setUserName`（trim 空则 no-op）/ `setUserAvatar`（空→null 存 `''`）
   - Controller 透传 2 getter + 2 setter（notifyListeners）

2. 新增 `lib/shared/widgets/user_avatar.dart`
   - `UserAvatar({avatarB64, size=60, onTap})`，平移 profile 三段逻辑（渐变外圈 / ClipOval 图 + errorBuilder 回退 / 默认人形），取色 appTheme

3. `lib/pages/profile_page.dart`
   - 删 `_readSetting` 与头像三私有方法；用户卡换 `UserAvatar(size:60, ...)`
   - 身份读写改走 `SettingsController`（`_loadAll` 身份同步赋值、摘要异步）；3 个写点改 controller setter

4. `lib/pages/main_shell_page.dart`
   - SliverAppBar 保持 plain（不折叠），加 `toolbarHeight≈116` + `titleSpacing:20`
   - title 换 `_buildWelcomeHeader`：`UserAvatar(≈52, onTap: _switchToProfileTab)` + `Text.rich`（用户名 primary/w700 强调，**显式 softWrap:true, maxLines:2, ellipsis**）
   - 新增 `_switchToProfileTab()`（setState `_selectedId='profile'`）

## 关键风险

- AppBar title 默认 `softWrap:false` → `Text.rich` 必须显式 `softWrap:true` 才能折行。
- title 超高会上下裁切 → 头像≤52、maxLines:2、toolbarHeight≥116。
- 勿误加 `expandedHeight`（触发折叠动画，违背常驻大气）。
- 头像空串先判空再 decode，decode 包 try + errorBuilder 回退。

## 落地顺序

doc 归档 → settings_service → user_avatar → profile_page → main_shell → analyze/test → 手测 → commit。
