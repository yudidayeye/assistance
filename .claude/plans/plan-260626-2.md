# 优化开发计划 v2 — 生理期UI微调 + 工具箱卡片增强 + 用户模块 + Tab栏

## 概述

基于 `requirement-260626-2.md`，对生理期日历详情页、工具箱卡片、Tab栏、我的页和设置页进行细节优化。

---

## 阶段 A：生理期记录 UI 微调

### A.1 日历与详情面板间距压缩

**问题**：当前 `DateDetailPanel` 的 `margin: EdgeInsets.fromLTRB(20, 0, 20, 16)`，日历 `Padding: LTRB(20, 8, 20, 8)`，两者间隙偏大，且详情面板有 `padding: 20` + `margin: 16` 底边距。

**改动文件**：
- `lib/modules/period_tracker/pages/calendar_page.dart` 行 102-120（日历 padding）
- `lib/modules/period_tracker/widgets/date_detail_panel.dart`（详情面板 margin/padding）

**步骤**：
1. calendar_page：日历底 padding 从 `(20, 8, 20, 8)` 减小
2. date_detail_panel：标题图标的 `Container(40x40)` 缩小 + 去掉 `color: appTheme.rose.withAlpha(20)` 底色 → 减小高度
3. date_detail_panel：内部 `padding: const EdgeInsets.all(20)` 减小 → `EdgeInsets.fromLTRB(16, 12, 16, 12)`

---

### A.2 日期详情面板样式优化

**问题**：
- 标题图标区域过大（40×40 container + icon）
- 备注行样式与"姨妈来了"行不一致（备注行图标颜色 `earthMedium` vs 姨妈行图标是 `rose`）
- "默认经期4天"文字不需要
- 按钮打开有报错（可能 Switch 组件 `onChanged` 在异步操作中状态不对）

**改动文件**：
- `lib/modules/period_tracker/widgets/date_detail_panel.dart`

**步骤**：
1. 标题图标行：去掉 `Container(40×40)` 和 `decoration` 底色，缩小图标 `size: 16`，文字 `fontSize: 14`
2. "姨妈来了"行：去掉 `'默认经期$_defaultPeriodDays天'` 副标题，只保留主标题文字
3. 备注行：去掉 `Divider`，样式改为和姨妈行一致的 `Row` + `Icon(20)` + `Expanded(TextField)`
4. 去掉两个 `Divider` 分隔线，各区域用 SizedBox 小间距隔开
5. 修复 Switch 报错：确保 `_togglePeriod` 调用后 `_saving` 标志位正确复位，避免 onChanged 同步异常

---

### A.3 预测卡片样式统一

**问题**：预测卡片（`_buildPredictionCard`）使用渐变背景，与日期详情面板（白底+边框+圆角）风格不统一。

**改动文件**：
- `lib/modules/period_tracker/pages/calendar_page.dart`（`_buildPredictionCard` 方法）
- `lib/modules/period_tracker/pages/calendar_page.dart`（`_buildEmptyPrediction` 方法）

**步骤**：
1. `_buildPredictionCard`：去掉渐变背景，改为 `Colors.white` + `BorderRadius.circular(20)` + `Border.all(color: earthMedium.withAlpha(20))`
2. 与日期详情面板的 padding/margin 保持一致
3. `_buildEmptyPrediction` 同样调整

## 阶段 B：我的页 — 用户信息存储

### B.1 用户信息服务 + 编辑弹窗

**问题**：当前用户卡片静态显示"点击编辑个人信息"，但不可编辑、不持久化。

**改动文件**：
- `lib/core/storage/database_service.dart` — 新增 `user_profile` 表（v4 migration）
- `lib/pages/profile_page.dart` — 添加编辑弹窗交互

**步骤**：
1. DB v4：`CREATE TABLE IF NOT EXISTS user_profile (key TEXT PRIMARY KEY, value TEXT NOT NULL)` 或直接用 `app_settings` 存
   - 实际更简单：复用 `app_settings` 表，用 key `user_name` / `user_avatar` 存储
2. 新建 `lib/core/settings/user_service.dart` — 单例，读写用户名
   - `Future<String?> getUserName()`
   - `Future<void> setUserName(String name)`
   - 默认 "用户"
3. 改造 `ProfilePageContent` 为 `StatefulWidget`
   - 加载时读取用户名
   - 点击用户卡片 → `showDialog` 弹出简易编辑框
   - 保存后持久化 + 刷新展示

## 阶段 D：工具箱卡片增强

### D.1 FeaturedCard 支持摘要展示

**问题**：当前卡片仅显示图标 + 标题，无业务摘要信息。

**改动文件**：
- `lib/shared/widgets/featured_card.dart` — 底部增加 summary 区域
- `lib/modules/accounting/accounting_module.dart` — `getSummary()` 返回本月总消费
- `lib/modules/period_tracker/period_module.dart` — `getSummary()` 返回预测经期日期

**步骤**：
1. `FeaturedCard` 新增 `summary` 可选参数（`String?`），底部一行小字展示
   - 记账卡片：`'本月支出 ¥xxx'` → 改动 `AccountingModule.getSummary()` 改用 `getMonthExpenseTotal`
   - 经期卡片：`'下次经期 x月x日'` → 已有 `getSummary()` 返回 `line1`
2. `FeaturedCard` 布局调整：图标用 `color`（模块主题色），摘要小字用 `appTheme.earthMedium`
3. `AccountingModule.getSummary()` 改为查询本月而非本日：
   ```dart
   final monthExpense = await TransactionService.instance.getMonthExpenseTotal(DateTime.now());
   return ModuleSummary(line1: '本月支出 ¥${FormatUtils.formatAmount(monthExpense)}');
   ```

### D.2 工具箱标题去"欢迎使用"

**问题**：MainShellPage 标题上方有"欢迎使用"副标题，与"我的"页风格不统一。

**改动文件**：
- `lib/pages/main_shell_page.dart`

**步骤**：
1. 移除"欢迎使用" `Text` 和 `SizedBox(height: 4)`
2. 工具箱标题直接显示"工具箱"，样式保持不变（RobotoSlab 24 bold），与 ProfilePage 的"我的"（Playfair 28 bold）视觉对齐即可

## 阶段 E：Tab 栏交互与样式

### E.1 扩展点击热区

**问题**：Navigator 只有 `Icon` 和 `Text` 能触发点击，空白区域无响应。

**改动文件**：
- `lib/shared/widgets/toolbox_bottom_nav.dart`

**步骤**：
1. 当前 `GestureDetector` 包裹 `SizedBox(height: 82, child: Column(...))` — 热区已经是 82px 高，但宽度只有 `Expanded` 的份额。实际上整个 `Expanded` 都应该是可点击的。
2. 修改：在 `_NavItem` 中 `GestureDetector` + `behavior: HitTestBehavior.opaque` 确保透明区域也响应
   - 或者给 `SizedBox` 加 `width: double.infinity`

### E.2 Tab 栏样式适配主题

**问题**：底部导航栏背景写死白色、上边框写死黑色透明度。

**改动文件**：
- `lib/shared/widgets/toolbox_bottom_nav.dart`

**步骤**：
1. 导航栏背景 `Colors.white` → `appTheme.creamDark`
2. 顶部边框 `Colors.black.withAlpha(18)` → `appTheme.earthMedium.withAlpha(15)`
