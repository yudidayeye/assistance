## A. 生理期记录 — 日期标签优化

### A.1 日期标签去底色 + 减间距
**文件**: `lib/modules/period_tracker/widgets/date_detail_panel.dart`

**当前问题**:
- DateDetailPanel 包裹在白色 Container 中（`color: Colors.white`），视觉上与日历卡片重复
- margin 上边距无（`LTRB(20,0,20,12)`），但日历下方 padding 为 `LTRB(20,8,20,4)`，日历与面板之间视觉间隙偏大
- 日期类型标签行与开关行之间 `SizedBox(height: 10)` 间隙偏大

**修改**:
1. 移除 Container 的白色背景（`color: Colors.white`），改为透明 — 让日期详情面板与页面背景融合
2. 保留圆角边框（`border`）做视觉分隔
3. 减小面板内部上 padding：`EdgeInsets.fromLTRB(16,12,16,12)` → `EdgeInsets.fromLTRB(16,8,16,8)`
4. 减小日期标签与开关行间距：`SizedBox(height: 10)` → `SizedBox(height: 6)`

### A.2 备注行样式美化
**文件**: `lib/modules/period_tracker/widgets/date_detail_panel.dart`

**当前问题**:
- 备注图标 `Icons.edit_note_rounded` 与 TextField 直接拼接，视觉单调
- TextField 无边框无填充，显得简陋

**修改**:
1. 将 TextField 改为有圆角背景的输入框：添加 `filled: true`、`fillColor`、`borderRadius: 8`
2. 将备注图标改为更美观的 `Icons.notes_rounded` 或 `Icons.sticky_note_2_rounded`
3. 优化 hintText 样式，字号从 12 调为 13
4. 调整整行间距：移除 `SizedBox(height: 4)` 上方的 gap，让布局更紧凑

## B. 周期统计 — 适应系统主题色

### B.1 统计卡片渐变适配主题
**文件**: `lib/modules/period_tracker/pages/stats_page.dart`

**当前问题**:
- 统计卡片 (`_buildStatsCard`) 使用 `appTheme.rose` + `appTheme.roseLight` 渐变背景
- 当用户切换到非 rose 主题（如 blue/green/gold）时，卡片色调与整体主题不协调
- 模块有 `themeColor`（`Color(0xFFC97D7D)`），UI 中未使用

**修改**:
1. 将统计卡片的渐变背景从 `appTheme.rose` 改为使用模块自身 themeColor：通过 `ModuleThemeExtension` 获取，或直接使用模块注册的 `themeColor`
2. 统计卡片内小图标底色从 `appTheme.rose.withAlpha(30)` 改为混合当前主题色
3. 分隔线颜色适配当前主题

**技术方案**:
- 方案一: 通过 `PeriodTrackerModule().themeColor` 获取模块色（简单直接，需 import module）
- 方案二: 使用 `Theme.of(context).moduleTheme.moduleColor`（需要确保 ModuleThemeExtension 已正确设置）
- **选择方案一** — 更可靠，不依赖 Theme 层级是否正确设置了 ModuleThemeExtension
