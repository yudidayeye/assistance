```
SliverAppBar      「我的」+ 齿轮 → push('/settings')（保留）
```

## 实现要点
- 数据源：`ModuleRegistry.instance.getModule('period_book'|'period_tracker'|'vault')`，按 `SettingsService.instance.isModuleEnabled(id)` 过滤；`getSummary()` 填充 line1/line2。
- 快捷操作：
  1. 记录经期 `favorite` → push('/period_tracker')；
  2. 记账 `wallet` → `getOngoingPeriod()==null ? push('/period_book/new') : push('/period_book')`；
  3. 锁定保险箱 `shield` → `hasMasterPassword()`：未设 push('/vault')；已设且未锁 `VaultSession.instance.lock()`+SnackBar；已锁则提示。
- 功能：`/period_tracker/stats`、`/period_book/history`、`/sync`。
- 设置：主题色点 = `ThemeProvider.instance.currentTheme.color`；版本 = `PackageInfo.fromPlatform().version`；均 push('/settings')。
- 订阅刷新：initState 里 addListener(PeriodBookService / PeriodService / VaultService / SettingsController)；dispose 移除；WidgetsBindingObserver 处理后台自动锁 vault 后的 resumed setState。
- 头像：`FilePicker.pickFiles(type: FileType.image, withData: true)` → `ui.instantiateImageCodec(bytes, targetWidth: 320, targetHeight: 320)` → PNG bytes → base64 → `upsertSetting('user_avatar', b64)`；展示 `Image.memory`；移除写空串。≤15MB 校验，解码异常 SnackBar 兜底。
- 昵称/头像读法收敛私有 `_readSetting(key)`（`query('app_settings', where:'key = ?')`）。
