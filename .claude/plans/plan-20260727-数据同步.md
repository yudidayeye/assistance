# 数据同步功能开发计划

## 需求

在设置页新增「数据同步」功能，支持手机和电脑之间**双向**数据同步。

## 技术方案

### 传输协议

局域网 HTTP 传输，双向对等：
- **接收方**：启动 HTTP Server，监听 POST 请求，接收 JSON 备份数据并导入
- **发送方**：调用 `generateExportBytes()` 生成备份，通过 HTTP POST 发送到接收方

手机→电脑、电脑→手机，流程完全一致，只是角色互换。

### 交互流程（以手机发送到电脑为例）

```
接收端（如电脑）                       发送端（如手机）
  │                                    │
  │  1. 点击「接收数据」                │
  │  2. 启动 HTTP Server               │
  │  3. 获取局域网 IP                   │
  │  4. 显示 IP:端口 + 二维码           │
  │                                    │
  │                         5. 点击「发送数据」
  │                         6. 输入 IP:端口（手动）
  │                         7. 生成备份 bytes
  │  ◄──── 8. POST /sync/upload ────── │
  │  9. 校验 JSON 结构                  │
  │  10. 弹出确认对话框                  │
  │  11. 用户确认 → executeImport       │
  │  ──────── 200 OK ────────────────► │
  │                         12. 显示成功
```

反向（电脑→手机）流程相同，手机端点「接收数据」起服务，电脑端点「发送数据」输入 IP 发送。

## 文件变更清单

### 1. 新建 `lib/core/sync/sync_service.dart`

同步服务核心类，收发两端对等，任何平台都可扮演任一角色：

```dart
class SyncService {
  static final instance = SyncService._();

  // ── 接收端 ──
  HttpServer? _server;
  bool get isRunning => _server != null;

  /// 启动 HTTP 服务，返回端口号
  Future<int> startServer();

  /// 停止 HTTP 服务
  Future<void> stopServer();

  /// 获取本机局域网 IP
  Future<String?> getLocalIp();

  // ── 发送端 ──

  /// 发送备份数据到目标地址
  Future<SyncResult> sendData(String targetIp, int port);
}
```

**接收端实现要点：**
- 使用 `shelf_io.serve()` 启动 HTTP 服务
- 监听 `0.0.0.0` 随机端口（避免冲突）
- 路由：`POST /sync/upload` 接收 JSON body
- 收到数据后写入临时文件，调用 `ImportExportService.previewImportFromPath()` 校验
- 返回校验结果给调用方（UI 层弹确认框）
- 确认后调用 `ImportExportService.executeImport()`

**发送端实现要点：**
- 调用 `ImportExportService.instance.generateExportBytes()` 获取备份
- 用 `dart:io` HttpClient POST 到 `http://<ip>:<port>/sync/upload`
- Content-Type: `application/json`

### 2. 修改 `lib/core/settings/settings_page.dart`

在设置页「数据」分区中，新增两个功能项（手机和电脑显示相同）：

```
┌──────────────────────────────────┐
│ 数据                             │
├──────────────────────────────────┤
│ 📥 导入数据                      │
│ ─────────────────────────────── │
│ 📤 导出数据                      │
│ ─────────────────────────────── │
│ 📡 接收数据                ← 新增 │
│ ─────────────────────────────── │
│ 📲 发送数据                ← 新增 │
│ ─────────────────────────────── │
│ 🗑️ 清除业务数据                  │
└──────────────────────────────────┘
```

- 「接收数据」→ 跳转接收页面（起服务、显示 IP + 二维码）
- 「发送数据」→ 跳转发送页面（输入 IP、发送备份）

### 3. 新建 `lib/core/sync/sync_receive_page.dart`

接收页面 UI（手机和电脑通用）：
- 顶部显示本机 IP 和端口
- 中间显示二维码（用 `qr_flutter` 生成，对方扫码可获取 IP）
- 底部显示连接状态（等待中 / 已收到数据 / 导入成功）
- 「停止接收」按钮

### 4. 新建 `lib/core/sync/sync_send_page.dart`

发送页面 UI（手机和电脑通用）：
- 输入框：手动输入目标 IP:端口
- 「发送」按钮
- 进度状态：发送中 / 成功 / 失败

## 实现步骤

1. **添加依赖** — `pubspec.yaml` 添加 `qr_flutter`
2. **创建 SyncService** — `lib/core/sync/sync_service.dart`
   - `getLocalIp()` — 遍历 `NetworkInterface` 获取局域网 IP
   - `startServer()` — shelf HTTP server，POST /sync/upload
   - `stopServer()` — 关闭 server
   - `sendData()` — generateExportBytes + HttpClient POST
   - 接收端处理：写临时文件 → preview → 返回校验结果
3. **创建接收页面** — `lib/core/sync/sync_receive_page.dart`
   - IP + 端口显示
   - QR 码生成
   - 连接状态管理
   - 收到数据后弹确认框 → executeImport
4. **创建发送页面** — `lib/core/sync/sync_send_page.dart`
   - IP 输入
   - 发送逻辑
   - 结果展示
5. **修改设置页** — `settings_page.dart`
   - 数据分区新增「接收数据」「发送数据」入口
6. **添加路由** — `app_router.dart`
   - `/sync/receive` → SyncReceivePage
   - `/sync/send` → SyncSendPage
7. **测试** — 两台设备在同一 WiFi 下互发测试
