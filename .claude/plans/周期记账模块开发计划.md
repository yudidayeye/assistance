## Phase 1：数据模型 + Service 层 + 建表 + 全局设置

### 1.1 数据库升级（v3 → v4）

**文件：** `lib/core/storage/database_service.dart`

- 将 `_currentVersion` 从 3 改为 4
- 在 `_onUpgrade` 中添加 v4 迁移：
  - 创建 `mod_period_book_periods` 表（含 `is_closed` 字段）
  - 创建 `mod_period_book_additions` 表
  - 创建 `mod_period_book_expenses` 表
  - 创建索引：`idx_pb_periods_start_date`、`idx_pb_expenses_period`

### 1.2 数据模型（3个文件）

**目录：** `lib/modules/period_book/models/`

- `period_record.dart` — PeriodRecord 实体类
  - `id`, `startDate`, `endDate`, `inProgressDate`, `baseAmount`, `balance`, `isClosed`, `createdAt`, `updatedAt`
  - `toMap()` / `fromMap()` 序列化
  - `get totalDays` getter（计算周期天数）
  - `get isOngoing` getter（未关闭即进行中）
  
- `addition_record.dart` — AdditionRecord 实体类
  - `id`, `periodId`, `amount`, `reason`, `createdAt`
  - `toMap()` / `fromMap()`

- `expense_record.dart` — ExpenseRecord 实体类
  - `id`, `periodId`, `category`('shopping'/'other'), `amount`, `description`, `createdAt`
  - `toMap()` / `fromMap()`

### 1.3 Service 层

**文件：** `lib/modules/period_book/services/period_book_service.dart`

- 单例模式 `PeriodBookService.instance`
- **CRUD：**
  - `createPeriod()` — 新建周期，返回 id
  - `getOngoingPeriod()` — 获取当前进行中的周期（is_closed=0 且最新）
  - `getAllPeriods()` — 获取所有周期（按 start_date 倒序）
  - `getClosedPeriods()` — 获取已关闭周期列表
  - `getPeriodById(int id)` — 按 ID 获取
  - `updatePeriod(int id, Map values)` — 更新周期（修改 end_date / in_progress_date / balance / is_closed）
  - `closePeriod(int id)` — 标记周期为已结束
  - `deletePeriod(int id)` — 删除周期及关联数据

- **追加记录：**
  - `addAddition(int periodId, double amount, String reason)` — 追加本金
  - `getAdditionsByPeriod(int periodId)` — 获取某周期的追加记录
  - `deleteAddition(int id)` — 删除追加记录

- **支出明细：**
  - `addExpense(int periodId, String category, double amount, String description)` — 记一笔
  - `getExpensesByPeriod(int periodId)` — 获取某周期支出明细（按 category 分组）
  - `getExpensesByCategory(int periodId, String category)` — 按分类获取
  - `deleteExpense(int id)` — 删除支出明细

- **计算逻辑：**
  - `getPeriodCalculations(int periodId)` → 返回 `{totalBase, shoppingTotal, otherTotal, balance, livingTotal, livingDailyAvg, totalDays}`
  - 余额为 null 时 living 相关字段返回 null

### 1.4 全局设置 — 发薪日配置

**文件：** `lib/modules/period_book/services/period_book_settings.dart`

- 从 `app_settings` 读写 `period_book_payday`（默认10）
- `getPayday()` → int
- `setPayday(int day)` → Future<void>
- `getDefaultStartDate()` → DateTime（当月发薪日）
- `getDefaultEndDate()` → DateTime（下月发薪日前一天）

### 1.5 模块定义

**文件：** `lib/modules/period_book/period_book_module.dart`

- 实现 `ToolModule` 接口
- `moduleId = 'period_book'`
- `displayName = '周期记账'`
- `icon = Icons.account_balance_wallet_rounded`
- `themeColor = Color(0xFF7B8BAA)`（柔夜蓝）
- `onRegister()` — 初始化默认发薪日设置
- `getSummary()` — 返回当前周期 line1=line2 摘要
- `buildSubRoutes()` — 子路由：`history`, `new`, `add-expense`, `edit-expense/:id`

### 1.6 路由注册

**文件：** `lib/main.dart`

- 添加 `import 'modules/period_book/period_book_module.dart'`
- 在 `registerAll()` 中添加 `PeriodBookModule()`

### 1.7 首页卡片支持 line2

**文件：** `lib/shared/widgets/featured_card.dart`

- 修改 `_loadSummary()` 保存完整 `ModuleSummary` 对象（而非只存 line1）
- 在卡片中增加显示 line2 的 Text widget

## Phase 2：当前周期详情页（入口页）+ 新建周期页

### 2.1 当前周期详情页

**文件：** `lib/modules/period_book/pages/period_detail_page.dart`

- **入口页**，进入模块直接展示
- 无周期时 → 空状态引导创建（FeaturedCard 风格）
- **顶部导航栏：**
  - 日期范围标题（如 `06月09日 ~ 07月10日`）
  - 右侧：历史记录按钮 + 编辑按钮
- **汇总卡片：** 6 项数据（总本金/购物/其他/余额/生活/生活日均）
  - 余额旁编辑按钮 → 弹出 NumberKeyboard 修改
- **追加记录区域：** 列表 + "追加本金"按钮
- **支出明细区域：** 购物/其他分组列表 + "记一笔"按钮
  - 左滑删除
- **图表区域占位：** 先预留 SectionLabel，Phase 5 实现
- 下拉刷新更新数据

### 2.2 新建周期页

**文件：** `lib/modules/period_book/pages/new_period_page.dart`

- 表单：
  1. 开始日期 — 默认当月发薪日，可改
  2. 结束日期 — 默认下月发薪日前一天，可改但**不可清空**
  3. 初始本金 — NumberKeyboard 输入
  4. 余额 — 可选，留空显示缺省
- 日期选择器使用 Flutter 原生 `showDatePicker`
- 创建成功后返回详情页

### 2.3 路由配置

**文件：** `lib/modules/period_book/period_book_module.dart`

- 入口页 → `/period_book` → `PeriodDetailPage`（展示当前周期）
- 子路由：
  - `/period_book/new` → `NewPeriodPage`
  - `/period_book/history` → `PeriodHistoryPage`（Phase 3）
  - `/period_book/add-expense` → `AddExpensePage`（Phase 4）

### 2.4 提交

```bash
git commit -m "Phase 2: 当前周期详情页（入口页）+ 新建周期页"
```
