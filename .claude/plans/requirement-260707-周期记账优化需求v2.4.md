# 周期记账优化需求 v2.4

> 基于 v2.3 增量变更，以下为新增/修改项。

---

## 1. 阶段卡片展开/收起按钮移至卡片下方

- 将展开/收起触发按钮从**卡片头部/右上角**移到**卡片底部**
- 卡片头部仅用于信息展示，点击头部不再触发展开/收起
- 卡片底部新增明确的「展开明细」/「收起明细」按钮
- 保持现有的展开动画和明细展示逻辑不变

涉及文件：`stage_card.dart`、`period_detail_page.dart`

---

## 2. 阶段编辑页内嵌添加支出/追加表单（无弹窗）

- 阶段编辑页的支出卡片和追加卡片内各新增一个「添加」操作入口
- 点击「添加支出」后，在**当前卡片内部下方**展开添加表单（分类选择 + 金额输入 + 描述），**不打开弹窗**
- 点击「添加追加」后，同样在卡片内部下方展开追加表单（金额输入 + 描述），不弹窗
- 表单展开后，用户填写完点击确认，数据直接添加到当前阶段的支出/追加列表
- 支持多次连续添加（添加后表单清空但不收起，或自动收起根据 UX 判断）

涉及文件：`stage_edit_page.dart`、`add_expense_page.dart`（评估删除）

---

## 3. 阶段日期支持设置「当前日期」

- 阶段模型中新增 `currentDate` 字段（String?，yyyy-MM-dd 格式），**默认值为阶段结束日期**
- 该字段表示用户在阶段中记录时的"当前日期"，用于计算生活费日均的天数基准
- 计算逻辑：
  - 如果设置了 `currentDate`，则天数 = `currentDate` - `startDate` + 1
  - 如果未设置（为 null），则天数 = `endDate` - `startDate` + 1（保持原有行为）
- 示例：开始日期 1 号，结束日期 7 号，当前日期设为 3 号 → 生活费日均天数 = 3 天
- 阶段编辑页中提供日期选择器设置该字段

涉及文件：`stage_record.dart`、`period_book_service.dart`、`stage_edit_page.dart`、`database_service.dart`

---

## 4. 历史记录页面改为表格样式，支持删除

- 历史记录页面从卡片列表改为**表格样式**展示
- 表格列包含：周期名称、开始日期、结束日期、总支出、总追加、净支出、操作
- 每行右侧提供「删除」按钮，点击后弹出确认框，确认后删除该周期及其关联数据
- 表格支持滚动，固定表头；移动端列过多时可横向滚动，或精简为关键列

涉及文件：`history_page.dart`、`period_book_service.dart`
