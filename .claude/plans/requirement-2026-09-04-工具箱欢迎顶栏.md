# 需求：工具箱顶栏改「欢迎区」（头像 + 欢迎语）

日期：2026-09-04

## 背景

「我的」页已支持用户头像与昵称（存 `app_settings.user_name` / `user_avatar`），但工具箱首页顶栏仍是固定标题「工具箱」，与用户身份割裂。希望首页更有个人感。

## 需求描述

1. 工具箱顶栏改为**加高的大气欢迎区**，文案「欢迎来到 {用户名} 的工具箱」，用户名做主题色强调。
2. 该区展示用户**圆形头像**：未设头像显示默认人形图标；已设显示 base64 头像图。
3. **仅点击头像**切换到底部「我的」Tab（不 push 路由，无返回栈）。
4. 顶栏右侧保留现有 ⋮ 更多菜单（展示样式 双列/单列 + 模块管理入口）。

## 交互决策（已确认）

- 顶栏布局：**加高两行（大气）**——头像与欢迎语同处加高顶栏，昵称过长可自动折两行，不做单行硬压。
- 点击热区：**仅头像**；欢迎语/整行不跳转。

## 验收标准

- 冷启动见默认人形头像 + 「欢迎来到 用户 的工具箱」。
- 「我的」页改昵称 / 设头像 / 移除头像后，切回工具箱立即同步。
- 点头像切到「我的」，无返回栈。
- 长昵称两行内折行、超宽省略；状态栏背景完整、无裁切/溢出。
- 导入含用户设置的备份后两端同步刷新。
