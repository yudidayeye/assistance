# 密码保险箱模块实现计划（修订版）

> 本文档已按照你的要求修订：仅加密「密码字段」；标题/备注明文存储；复制密码后不清除剪贴板；且仅凭数据库文件无法反向破解或解密任何密码内容（主密码不存储、派生密钥不落盘）。

---

## 一、加密方案（简化版）

```
用户输入主密码
   ↓
主密码 + 随机盐 → Argon2id → 256-bit 派生密钥（仅驻留内存）
   ↓
派生密钥 → AES-256-GCM 加密「密码字段」
标题、备注 → 明文存储
```

数据库中存储：
- salt（随机生成）
- verify_cipher + verify_iv（加密固定字符串，用于验证主密码是否正确）
- encrypted_password + password_iv（每条记录独立 IV）

数据库中永远不存储：主密码、派生密钥

## 二、数据库表设计（v13 迁移）

```sql
-- 主密码验证表（仅一行）
CREATE TABLE mod_vault_master (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  salt TEXT NOT NULL,              -- Argon2id 盐（hex）
  verify_cipher TEXT NOT NULL,     -- 加密的验证字符串（hex）
  verify_iv TEXT NOT NULL,         -- IV（hex）
  created_at TEXT NOT NULL
);

-- 分类表
CREATE TABLE mod_vault_categories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  icon TEXT NOT NULL DEFAULT 'folder',
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- 密码条目表
CREATE TABLE mod_vault_entries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  category_id INTEGER NOT NULL,
  title TEXT NOT NULL,                     -- 明文
  encrypted_password TEXT NOT NULL,        -- AES-GCM 密文（hex）
  password_iv TEXT NOT NULL,               -- IV（hex）
  note TEXT,                               -- 明文（可为空）
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  FOREIGN KEY (category_id) REFERENCES mod_vault_categories(id) ON DELETE CASCADE
);
```

## 四、页面流程

1. 首次进入模块
   - 检测到无主密码 → MasterPasswordPage（设置主密码）
   - 设置成功 → 进入 VaultEntryPage（分类列表）

2. 再次进入模块
   - VaultSession 无有效密钥 → MasterPasswordPage（输入主密码验证）
   - 验证成功 → 进入 VaultEntryPage

3. 分类列表页（VaultEntryPage）
   - 显示所有分类卡片
   - 支持：新增分类、编辑分类、删除分类
   - 点击分类 → CategoryEntriesPage

4. 分类条目列表页（CategoryEntriesPage）
   - 显示该分类下所有密码条目（标题 + 密码遮罩）
   - 支持：新增条目、编辑、删除
   - 点击条目 → ViewEntryPage（需要再次验证）

5. 查看密码详情页（ViewEntryPage）
   - 再次输入主密码验证（或从 VaultSession 读取缓存密钥）
   - 显示：标题、明文密码（可复制）、备注
   - 支持：编辑、删除

## 五、安全交互设计

1. 自动锁定：App 切到后台超过 30 秒，清除内存中的密钥，回来需重新输入。
2. 密码遮罩：所有列表页密码默认 `••••••` 显示。
3. 复制密码：不清除剪贴板（按要求去掉该策略）。
4. 密钥零持久化：派生密钥永远不写入磁盘/SharedPreferences。
5. 主密码不可找回：忘记主密码 = 数据全部丢失（需明确提示用户牢记）。
