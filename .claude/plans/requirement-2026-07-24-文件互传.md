# 文件互传模块 — 需求文档

## 1. 概述

在手机（Android）和电脑（Windows）之间实现局域网文件互传功能，作为工具箱 App 的新模块集成。

## 2. 目标用户场景

- 手机照片/视频快速传到电脑
- 电脑上的文档/文件传到手机
- 不需要数据线、不需要第三方工具（如微信文件传输助手）

## 3. 功能需求

### 3.1 核心功能

| 功能 | 说明 |
|------|------|
| 手机→电脑传文件 | 手机选择文件，推送到电脑指定目录 |
| 电脑→手机传文件 | 手机浏览电脑共享目录，选择文件拉取到本地 |
| 目录浏览 | 手机端可浏览电脑共享文件夹的目录结构 |
| 文件选择 | 手机端支持选择单个/多个文件传输 |
| 传输进度 | 实时显示文件传输进度和速度 |

### 3.2 连接管理

| 功能 | 说明 |
|------|------|
| 手动输入 IP | 用户手动输入电脑 IP 地址连接 |
| 连接配置保存 | 保存常用电脑的 IP、端口、共享路径等配置 |
| 连接状态 | 显示当前连接状态（已连接/未连接/连接中） |

### 3.3 传输记录

| 功能 | 说明 |
|------|------|
| 传输历史 | 记录每次传输的文件名、大小、方向、时间 |
| 首页摘要 | 显示最近传输记录和传输状态 |

## 4. 安全需求

局域网内其他设备可能尝试访问共享资源，需从两端同时防护：

### 4.1 手机端 HTTP Server 防护

| 措施 | 说明 |
|------|------|
| **连接码认证** | 服务器启动时自动生成 6 位随机连接码，电脑浏览器访问时必须输入连接码才能进入 |
| 连接码有效期 | 每次启动服务器重新生成，不持久化，关闭即失效 |
| API 鉴权 | 所有 `/api/*` 接口需携带连接码 token，否则返回 401 |
| 访问提示 | 手机端页面实时显示当前连接码，方便用户查看输入 |

### 4.2 电脑端共享文件夹防护

| 措施 | 说明 |
|------|------|
| **专用账户** | 创建一个低权限 Windows 本地账户专门用于文件共享访问 |
| **隐藏共享** | 共享名加 `$` 后缀（如 `PhoneShare$`），在网络邻居中不可见 |
| **权限最小化** | 该账户仅对指定共享文件夹有读写权限，无其他系统权限 |
| **密码保护** | 手机 SMB 连接时必须输入该账户的用户名和密码 |

### 4.3 安全层级总览

```
┌─────────────────────────────────────────────┐
│ 层级 1：隐藏共享（PhoneShare$）              │
│ → 别人在网络邻居中看不到共享文件夹            │
├─────────────────────────────────────────────┤
│ 层级 2：专用账户 + 密码                      │
│ → 即使知道共享路径，没有密码也无法访问        │
├─────────────────────────────────────────────┤
│ 层级 3：HTTP 连接码                          │
│ → 别人访问手机 IP 也无法进入 Web 页面         │
└─────────────────────────────────────────────┘
```

## 5. 非功能需求

| 项目 | 要求 |
|------|------|
| 平台 | Android（手机端）+ Windows（电脑端） |
| 网络 | 同一 WiFi 局域网，无需互联网 |
| 协议 | HTTP（局域网内传输，不加密） |
| 文件大小 | 支持大文件传输（视频等），需流式传输 |
| 断点续传 | v1.0 暂不支持，后续版本考虑 |
| 安全性 | 连接码 + 专用账户 + 隐藏共享，三层防护 |

## 6. 技术方案选型（结论）

采用 **"手机端内置 HTTP Server"** 方案：

- 手机端 Flutter App 内置 HTTP 文件服务器
- 电脑端通过浏览器访问手机 IP 地址进行文件上传/下载
- 手机端主动连接电脑共享文件夹（SMB）浏览和拉取文件
- 电脑端仅需一次性运行一个自动生成的 .bat 脚本（开启 SMB 共享）

详见技术方案文档。

## 7. 不包含（v1.0 范围外）

- USB 数据线传输
- 断点续传
- 文件加密传输
- iOS 平台支持
- 跨网段/互联网传输
- 自动设备发现（mDNS）
