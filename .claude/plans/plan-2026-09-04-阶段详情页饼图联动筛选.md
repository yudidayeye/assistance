# 计划：阶段详情页饼图联动「个人支出」列表筛选

- 日期：2026-09-04
- 模块：周期记账（period_book）

## 现状关键点

- StageCard 内饼图选择状态自封闭（`int? _touchedIndex` 仅控制 tooltip），页面感知不到选择。
- RecordsTabCard 的 tab 索引完全内部管理，外部无法切换。
- StageEditPage 已持有本阶段全部 `_expenses`，「个人支出」列表由 `_buildShoppingSection` 过滤 `!e.isOther` 得到；分类显示名通过 `_mapCategoryForDisplay` 与饼图 key（显示名）一致。
- StageCard 同时被周期概览页复用（不传回调时不产生任何副作用）。
- 饼图 key 为显示名（生活/购物/…/杂项），「杂项」来自漏记倒推 livingTotal，无真实条目 → 需空态特判。

## 改动方案

### 1. widgets/stage_card.dart
- 新增可选参数 `ValueChanged<String?>? onBreakdownCategorySelected`（null=取消），加入构造函数。
- 内部选中状态 `int? _touchedIndex` → `String? _touchedCategory`（按名称，防数据刷新后索引漂移）；`didUpdateWidget` 在 stage.id 变化时重置。
- 点击回调把 `touchedSectionIndex` 映射回分类名（点空白 → null），抽 `_handleBreakdownCategoryTap`：同扇区重复点击/点空白 → 置 null 并回调 null；否则选中并回调分类名。
- tooltip 改为按 `_touchedCategory` 从 `sortedEntries` 反查最新金额/占比。

### 2. widgets/records_tab_card.dart
- 新增可选 `int? selectedIndex` 与 `ValueChanged<int>? onSelectedIndexChanged` 进入受控模式；未传时维持内部自管理，其他调用方（large_items_edit_page 等）行为不变。

### 3. pages/stage_edit_page.dart（核心页面）
- 新增状态：`int _recordsTabIndex`、`String? _expenseFilter`、`GlobalKey _recordsTabKey`。
- 顶部 StageCard 传 `onBreakdownCategorySelected: _onBreakdownCategoryChanged`。
- `_onBreakdownCategoryChanged`：`setState` 更新 `_expenseFilter`；选中有分类时切 `_recordsTabIndex=0` 并 `Scrollable.ensureVisible` 滚到列表区。
- RecordsTabCard 传受控 `selectedIndex` / `onSelectedIndexChanged`。
- `_buildShoppingSection`：
  - `allShopping`（全部非 other）→ 按显示名过滤得到 `shoppingExpenses`；
  - 有个人支出但筛空（如杂项）→ `emptyText` 显示「「$filter」分类暂无支出条目」；
  - 开启添加表单且筛选分类可添加时预置 `_shoppingCategory`，避免新条目被筛掉看不见；
  - 拖动排序逻辑抽 `_onShoppingReorder`；筛选激活时 `onReorder`/拖拽 `leading` 置 null 防错位。

## 不做的事
- 不改周期概览页与大额记录页（新参数缺省即可）；不改视觉配色/间距体系。

## 验证
1. `flutter analyze` 三个改动文件无新增告警（仅历史遗留告警）。
2. `flutter test test/modules/period_book` 全绿（15 项）。
