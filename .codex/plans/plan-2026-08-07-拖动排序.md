# 开发计划：分类与密码条目拖动排序

- 日期：2026-08-07

## 步骤

1. 数据库迁移 v16：`mod_vault_entries` 增加 `sort_order INTEGER NOT NULL DEFAULT 0`；`_createV13Schema` 同步更新；`_onUpgrade` 增加 `_migrateToV16`。
2. `VaultEntry` 模型增加 `sortOrder` 字段（fromMap/toMap/copyWith）。
3. `VaultService`：
   - `getEntriesByCategory` 排序改为 `sort_order ASC, created_at ASC`。
   - 新增 `reorderCategories(List<int> orderedIds)`：事务内批量写 `sort_order 0..n-1`。
   - 新增 `reorderEntries(int categoryId, List<int> orderedIds)`：同上。
4. 分类列表页 `vault_entry_page.dart`：
   - `ListView.builder` → `ReorderableListView.builder`（`buildDefaultDragHandles: false`，`onReorderItem`）。
   - 卡片右侧加 `ReorderableDragStartListener` 拖拽手柄。
   - `_handleCategoryReorder` 更新本地顺序并调用 `reorderCategories`。
5. 密码列表页 `category_entries_page.dart`：
   - 列表改为 `ReorderableListView.builder`。
   - 卡片结构包 `Row(Expanded(卡片内容), 拖拽手柄列)`，根节点加 `ValueKey`。
   - `_handleEntryReorder` 更新本地顺序并调用 `reorderEntries`。
6. 测试：`vault_service_test.dart` schema 增加 `sort_order`；新增 reorderCategories / reorderEntries / sortOrder 读写三个用例；`setUpVault` 清理历史数据保证用例独立。
7. 验证：`flutter analyze` + `flutter test test\modules\vault`。

## 风险点

- `onReorder` 已弃用，使用 `onReorderItem`（自动修正 newIndex）。
- ReorderableListView 要求每个 item 根节点带唯一 key。
- 测试内存库复用导致数据残留，需在建表后清理。
