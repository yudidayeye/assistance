# 需求文档：密码保险箱分类 Windows 桌面快捷方式

日期：2026-08-28

## 目标

支持在 Windows 版「密码保险箱」中，为指定分类创建桌面快捷方式。

## 使用流程

1. 用户在密码保险箱首页长按一个分类。
2. 在分类操作菜单中选择「创建桌面快捷方式」。
3. 应用在 Windows 桌面生成名称为「理解 - 分类名」的 `.lnk` 文件。
4. 双击该快捷方式启动应用，并直接进入对应的密码保险箱分类。

## 安全要求

- 快捷方式仅保存分类 ID，不包含密码、用户名、备注或主密码。
- 打开分类后的密码展示与解锁规则保持不变。
- 非 Windows 平台不显示该入口。

## 异常处理

- 创建失败时显示统一错误提示。
- 同名快捷方式覆盖更新，避免重复生成。
